# Roadmap

## M0 — Foundation (this pull request)

- pnpm workspace with an independent React package and Next.js showcase.
- Component quality contract and contribution guidelines.
- One accessible, responsive envelope interaction prototype.
- A simple interactive color playground and usage example.
- Minimal component interaction tests.

## M1 — Flagship envelope

- Review envelope construction and physical references.
- Refine flap fold, paper travel, seams, shadow continuity, seal and materials.
- Add optional open/close gestures, focus management, paper contents and real-world mobile ergonomics.
- User-test keyboard, touch, mouse, and reduced-motion behavior.
- Run automated build, accessibility and performance checks.
- Integrate an approved variant into the portfolio's In My Head page.

## M2 — Library foundations

- Stabilize controlled/uncontrolled interaction patterns.
- Theme tokens, CSS scoping, modular package exports, Storybook or custom demos.
- Package integration tests in Vite, Next.js and server-rendered React.
- Document API, browser support and design constraints.

## M3 — Collection alpha

- Interactive journal.
- Peelable sticky note.
- Public documentation and examples.

## M4 — Open-source release

- Semver, changesets, release pipeline, npm provenance.
- Public gallery, accessibility review and community contribution templates.

We favor a few exceptional objects over a long list of mediocre ones.
